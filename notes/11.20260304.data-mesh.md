## Notas

### 1. Definição
- Data Mesh é uma abordagem de arquitetura de dados que descentraliza a gestão, baseando-se em domínios de negócio.
- Substitui o modelo de centralização em data lakes ou data warehouses geridos por uma única equipe central.
- A responsabilidade é distribuída para os times que possuem o contexto do dado (times de produto ou áreas de negócio).

### 2. Princípios Fundamentais

#### Domínio orientado à propriedade dos dados
- Cada equipe de domínio (ex: Vendas, Logística) é a autoridade e responsável por seus próprios dados.

#### Dados como produto
- Os dados devem ser tratados com o mesmo rigor de um produto de software.
- Exige foco em qualidade, documentação, confiabilidade e facilidade de consumo.

#### Infraestrutura de dados como plataforma
- Provisão de uma plataforma de autoatendimento.
- Permite que domínios publiquem e consumam dados de forma autônoma, eliminando gargalos de times centrais.

#### Governança federada
- Equilíbrio entre centralização e descentralização.
- Padrões e princípios são compartilhados globalmente, mas a execução é descentralizada.
- Garante interoperabilidade, segurança e conformidade entre os diferentes domínios.


 **Data Mesh** é uma forma de organizar a arquitetura de dados baseada em **domínios**. Em vez de centralizar todos os dados em um **data lake** ou **data warehouse** gerido por uma equipe única, o **Data Mesh** distribui a responsabilidade para os **times que mais entendem os dados**: os times de produto ou áreas de negócio.

### Princípios do **Data Mesh**


1. **Domínio orientado à propriedade dos dados**  
    Cada time de domínio (ex: Vendas, Logística, Financeiro) é **responsável** por seus próprios dados como se fossem **produtos**.
    
2. **Dados como produto**  
    Os dados não são apenas subprodutos operacionais; eles devem ser tratados com a mesma seriedade de um produto de software — com qualidade, documentação e confiabilidade.
    
3. **Infraestrutura de dados como plataforma**  
    A organização fornece uma **plataforma de autoatendimento** que permite aos domínios publicarem, descobrirem e consumirem dados de forma **autônoma**, sem depender de times centrais.
    
4. **Governança federada**  
    A governança de dados é coordenada por princípios e padrões compartilhados, mas **executada de forma descentralizada**, garantindo **segurança, conformidade e interoperabilidade**.
