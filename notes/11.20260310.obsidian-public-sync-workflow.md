## Notas

O fluxo consiste em manter a soberania dos dados no cofre privado e utilizar um repositório intermediário (público) como espelho filtrado.

### 1. Preparação: Do Privado para o Público Local
O script Bash varre as notas do cofre principal em busca de notas que atendam aos critérios de metadados (`type: atomic` e `visibility: public`) e as copia para a pasta do repositório público local.

Script ./sync-public.sh:

```bash
#!/usr/bin/env bash


set -euo pipefail

SRC_DIR="./notes"
DEST_DIR="../../publicVault/notes"

mkdir -p "$DEST_DIR"

find "$SRC_DIR" -maxdepth 1 -type f -name '*.md' -print0 |
	while IFS= read -r -d '' file; do
		if grep -q 'type: atomic' "$file" && grep -q 'visibility: public' "$file"; then
			cp -fv "$file" "$DEST_DIR"/
		fi
	done
	
```

O script utiliza `find` e `grep` para identificar os arquivos e `cp -f` para sobrescrever a pasta de destino. 
O diretório publicVault/notes/ torna-se um espelho exato, porém filtrado, das suas notas públicas.
Após a cópia local, as alterações devem ser versionadas e enviadas para o servidor remoto.
