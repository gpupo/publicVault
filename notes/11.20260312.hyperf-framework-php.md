## Notas

### Visão Geral
- Framework [[PHP]] de alta performance voltado para aplicações CLI e microsserviços.
- Baseado em [[Swoole]] ou Open Swoole, utilizando o [[11.20260312.padrao-reactor|Padrão Reactor - Modelo Arquitetural para I/O Assíncrono]] para event loop.
- Habilita programação assíncrona real através de corrotinas, eliminando o overhead do PHP-FPM tradicional.

### Características Principais
- Alta Performance: Capacidade de processar milhões de requisições por segundo devido à memória persistente (o estado da aplicação não sofre reload a cada request).
- Ecossistema de Microsserviços: Suporte nativo para gRPC, filas (queues), circuit breaker, rate limiting, tracing distribuído e métricas.
- Arquitetura Moderna: Implementa Injeção de Dependência (DI), Programação Orientada a Aspectos (AOP), ORM assíncrono e Middlewares.
- Semelhança de DX: Estrutura de desenvolvimento similar ao Laravel, facilitando a curva de aprendizado para desenvolvedores PHP modernos.

### Casos de Uso e Implantação
- APIs de alta carga e concorrência massiva.
- Sistemas em tempo real (WebSockets), IoT e comunicação entre microsserviços.
- Execução: Roda como um servidor próprio via CLI (`php bin/hyperf.php start`), dispensando o uso de Apache ou Nginx como servidores de aplicação.



### Comparação de Modelo de Execução

| Característica | Modelo Tradicional (FPM)       | Modelo Hyperf (Swoole)                 |
| :------------- | :----------------------------- | :------------------------------------- |
| Ciclo de Vida  | Stateless (morre após request) | Stateful (persiste na memória)         |
| Servidor       | Apache / Nginx + FPM           | Standalone (CLI)                       |
| Concorrência   | Processos/Threads pesadas      | Corrotinas leves (Async)               |
| Performance    | Limitada pelo I/O bloqueante   | Alta escalabilidade I/O não-bloqueante |
