## Notas

### 1. Definição e Propósito
- **Agent Skills** é um formato aberto (inicialmente desenvolvido pela Anthropic) para equipar agentes de IA com expertises e capacidades específicas de forma portátil.
- Diferente de instruções customizadas (que são globais e estáticas), as Skills são **unidades de expertise modulares** carregadas sob demanda.
- Funcionam como uma "caixa de ferramentas" que o agente consulta apenas quando o contexto exige, otimizando o uso de tokens e a precisão das tarefas.

### 2. Anatomia de uma Skill
As Skills são geralmente organizadas em pastas contendo:
- `SKILL.md`: Arquivo principal com metadados (YAML frontmatter), instruções de "como fazer" e descrições para descoberta.
- **Recursos Adicionais**: Scripts executáveis, templates de código, checklists de revisão e documentação de domínio.
- **Progressive Disclosure**: O sistema carrega primeiro o nome/descrição; as instruções completas só entram no contexto se a skill for ativada.



### 3. Comparativo entre Plataformas (Status 2026)

| Ferramenta         | Implementação                | Uso Típico                                                            |
| :----------------- | :--------------------------- | :-------------------------------------------------------------------- |
| **Claude Code**    | Nativo (MCP integration)     | Comandos via slash (ex: `/review-pr`) e automação de workflow.        |
| **Cursor IDE**     | Composer Agent Skills        | Descoberta dinâmica de workflows e scripts de infraestrutura.         |
| **GitHub Copilot** | Agent Skills (Open Standard) | Automação de PRs, revisões LGPD e padrões de arquitetura corporativa. |

### 4. Exemplos Práticos de Workflows
- **Skill de Git Transacional**: Define que cada commit deve seguir o padrão *Conventional Commits* e exige um `npm test` bem-sucedido antes do push.
- **Skill de Compliance Jurídico**: Um módulo que escaneia strings de interface (UI) em busca de termos sensíveis ou violações de acessibilidade e LGPD.
- **Skill de Refatoração de Design Patterns**: Instruções específicas para converter herança em composição seguindo as preferências da equipe.

### 5. O Impacto no "Vibe Coding"
- Transforma o desenvolvimento experimental em um processo **auditável e repetível**.
- Permite que o desenvolvedor capture "conhecimento organizacional" em arquivos que viajam junto com o repositório (`.claude/skills` ou `.cursor/rules`), garantindo que qualquer colaborador (humano ou IA) siga os mesmos padrões.
